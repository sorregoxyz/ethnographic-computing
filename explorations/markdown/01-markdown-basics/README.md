# Introduction to Markdown

## Exploring Markdown

[Markdown](https://en.wikipedia.org/wiki/Markdown) is a lightweight markup language that allows us to create structured documents using plain text. It is widely used in digital documentation, collaborative writing, software development, and platforms such as [GitHub](https://github.com).

In this section, we explore Markdown as a tool for ethnographic writing, documentation, and the organization of research materials.

The aim is not simply to learn how to format text. We are interested in what becomes possible when ethnographic writing is created in a format that can be structured, linked, versioned, searched, published, and connected to computational environments.

## Explorations

1. **Markdown Basics** — Learn the fundamental syntax and create your first Markdown document.
2. **Writing Structured Fieldnotes** — Experiment with Markdown as a format for documenting ethnographic observations.
3. **Using Metadata and Frontmatter** — Introduce descriptive information, dates, identifiers, and tags.
4. **Linking Research Materials** — Connect documents, images, observations, and other research materials.
5. **Building a Field Diary** — Assemble a collection of dated and interconnected field entries.
6. **Publishing and Maintaining Documents** — Explore Markdown within GitHub and learn how to maintain and publish research documentation.

## Why explore Markdown?

Markdown offers an accessible entry point into computational practices. It does not require advanced programming knowledge, yet it introduces ways of thinking about structure, relationships, documentation, and information organization.

For ethnographic research, it can become a practical infrastructure for field diaries, research logs, methodological documentation, and collaborative archives.

## Further connections

These explorations connect with other areas of the laboratory, particularly Git and GitHub, data structures, documentation practices, and the development of hybrid ethnographic instruments.

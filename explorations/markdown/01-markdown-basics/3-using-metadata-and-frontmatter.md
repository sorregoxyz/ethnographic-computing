# Using Metadata and Frontmatter

## Exploring Metadata

A Markdown document contains written content, but it can also contain information describing the document itself. This information is called metadata.

For example, a fieldnote might contain an observation made in a park of a neighborhood of a city, on a particular date, as part of a research project on urban transformation. We might also want to know who wrote it, which topics it concerns, whether it includes photographs, and whether it is an original entry or a revised document. Metadata makes this information explicit.

In this exploration, we introduce YAML frontmatter as a simple way to describe Markdown documents and experiment with its possibilities for organizing ethnographic research materials.
